# Decisiones

- Se conserva Canvas 2D propio: evita introducir otro motor y mantiene las escenas y controles existentes.
- El respaldo remoto es una rama porque la conexión GitHub disponible no publica etiquetas; la etiqueta exacta existe en el repositorio git local.
- Las cifras económicas sintéticas se distinguen visualmente de datos oficiales. No se atribuirán a 2026 sin validación.
- La cohesión de la UE se modela como bloque con afinidad inicial y respuesta defensiva configurable; no se extrapolan relaciones políticas reales a todos los tratados.
- El desarrollo amplía el prototipo existente. Las funciones ausentes no se marcarán completas por aparecer en el diseño.
- Se limita la cámara a zoom 1–7 y traslación proporcional: evita mostrar superficies fuera del atlas.
- Las rutas marítimas adicionales son abstractas por proximidad costera; no se presentan como navegación de estrechos real.
- El editor usa portapapeles y datos JSON, nunca `eval` ni scripts JavaScript arbitrarios; las acciones permitidas tienen límites.
- No se publican salas online de solo cliente con contraseñas almacenadas públicamente. Requieren validación de servidor y un proyecto Appwrite separado; el transporte local se entrega operativo.
- Los escenarios de 1914, 1939, 1962 y 1990 no se fabrican con fronteras actuales, porque serían históricamente falsos. Se mantienen pendientes de cartografía y fuentes verificadas.
